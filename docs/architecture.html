Overview

text-emoji 是一個純前端 React 19 + Vite 7 單頁應用，同時以兩種形式交付：網頁版（GitHub Pages）與 Chrome 擴充功能側邊面板。全部功能（表情符號、文字符號、顏文字、空白工具、斷行工具）皆在瀏覽器內完成，資料寫死於前端 bundle，狀態靠 localStorage 持久化。

由上而下共 5 層，由實際讀取 vite.config.js / src/ / HANDOFF.md 整理而成，未讀到的細節一律標示「未確認」。

05建置與部署層

關鍵設計決定：一份原始碼、靠環境變數分岐成兩種輸出 —— vite.config.js 讀取 BUILD_TARGET，同時切換 base 路徑與 outDir，並用 rollupOptions.input 一次打包 index.html 與 sidepanel.html 兩個進入點。

▸ npm run build

▸ npm run build:gh

GitHub Pages 通道

outDir: dist-gh/　base: '/text-emoji/'
npm run deploy → gh-pages 套件推送
https://miku4ocean.github.io/text-emoji/
為什麼是 keystone：兩個發布形態（擴充功能 vs 網頁）共用同一顆 App 元件與同一份資料層，只靠建置設定分岐，避免了維護兩份程式碼的成本；也是本專案唯一橫跨「介面層」與「部署層」的結構性決定。
＋外部依賴 ／ 已知限制
  • Google Fonts CDN（Inter、Noto Sans TC）於 index.html / sidepanel.html <head> 以 <link> 載入；有 system-ui 字型 fallback chain。CDN 載入失敗時的實際降級行為未逐一驗證，標示「未確認」。
  • lucide-react 圖示套件：建置期打包進 bundle，非 runtime CDN 依賴。
  • EmojiTab／KaomojiTab 的搜尋列目前為裝飾用（filter 參數被忽略），非 bug 是既有留白，見 HANDOFF「下一步」建議之一。
